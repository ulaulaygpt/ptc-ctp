# Readable specifications

This directory exposes readable text representations of closed public PTC/CTP specifications so that their content can be inspected and diffed directly in GitHub.

## Authority and preservation

These text files are **not replacements for the canonical archived artefacts**. The corresponding Zenodo record remains the archival and citation authority. Each version directory contains a `SOURCE.yml` file linking the readable representation to the published DOI and the checksums of the canonical files.

## Current readable set

- `R-01/v1.1/` — ES / EN / FR
- `PTC-F/v1.2/` — ES / EN / FR
- `ARCH/v0.3/` — ES / EN / FR

FRS-01, PKG-02 and DCL-03 will enter this directory only from exact closed public sources that can be matched unambiguously to their Zenodo records.

> Zenodo preserves the canonical artefact. GitHub exposes a readable and auditable representation.
